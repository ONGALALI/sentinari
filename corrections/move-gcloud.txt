🚀 Step 1: Activate the Gemini API in Google Cloud

Before running the autonomous testing script, you must activate the correct API service within your paid Google Cloud Console.
1. Go directly to the Google Cloud Vertex AI Dashboard.
2. Select your active, paid Billing Project from the top project selector dropdown.
3. If prompted, click Enable Vertex AI API. (This activates the backend endpoint infrastructure for gemini-2.5-pro and gemini-2.5-flash).
4. Authentication Setup: Install the Google Cloud CLI locally and authenticate your terminal by running:bash
gcloud auth application-default login
Use code with caution.
This automatically creates a local credentials token that the Python SDK inherits natively without hardcoding risk-prone IAM API keys.

Vector Glossary

        
Plain-language terminology for reading the Qualia and model-comparison panels. Hover (or keyboard-focus) any dotted-underlined term anywhere in this lab — every tag opens a full explainer: what it is, its effect on the model, and what happens when it runs too high or too low.

        

          
Behavior VariantThe operating position on the behavior range. Low values are conservative and narrow; higher values allow broader, more exploratory responses.

          
Q0 VectorThe initial qualia state vector. In this lab it represents the starting semantic/interpretive state before the trajectory evolves.

          
A0 VectorThe initial attention vector. It shows where attention is pulled at the start of the response process.

          
S VectorThe stabilizing or attractor vector. It represents the direction the system is encouraged to settle toward.

          
AlphaThe weight given to a state's OWN direction when state (Q0), attention (A0) and stabilizer (S) are mixed each simulation step — all three weights normalized together. Higher alpha makes the trajectory persist and hold its shape.

          
BetaThe weight of the stabilizer (S) pull in the per-step mix. Higher beta pulls both state and attention toward the attractor each step.

          
GammaThe coherence/pressure term applied to the field. It helps shape how strongly the response trajectory is pulled into a coherent pattern.

          
Gamma CapThe maximum allowed gamma effect. It prevents the coherence pressure from overwhelming the simulation.

          
Stability BiasA damping force. Higher values resist drift and keep the trajectory more stable; lower values allow more movement.

          
Bell CurveThe weighting curve over behavior variants. It shows where the current variant sits relative to the preferred operating center.

          
Peak A zThe highest attention movement on the A z axis. It is used as a compact marker for the strongest attention event in the trajectory.

          
Stability IndexA normalized outcome signal estimating how coherent and stable the trajectory remained.

          
InfluenceThe amount of Qualia pull applied to the final behavior ratio. Higher influence means the vector field had more effect.

          
Reasoning ProxyA derived comparison score based on answer length and influence. It is not a true reasoning proof, but a useful local signal.

          
Logic ProxyA derived comparison score based on response structure and gamma pressure. It should be read as a heuristic, not a formal logic grade.

          
AnxietyInverse stability pressure. Lower anxiety is better in this lab because it means the response remained less volatile.
